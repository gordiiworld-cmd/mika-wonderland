# Wonderland Dream — только Round 6 (исходный дизайн)

## Что изменено
- Взяты исходные `index(1).html` и `styles(1).css`, а не новый макет. Все старые CSS-правила сохранены без изменений; новые правила дописаны **в конец** `styles.css` и влияют только на шестой раунд.
- Исходная шапка, заголовок **ROYAL GARDEN**, расположение видео, шага задания и подвала сохранены.
- Добавлены четыре отдельных интерактивных силуэта без видимых карточек и рамок. PNG сделаны из четырёх присланных JPEG (удалён светлый фон). Порядок: **ромб → сердце → трефа → пика**. **Третий ключ (трефа) — правильный**.
- Выбранный ключ летит к целевой точке видео с уменьшением и поворотом, повторные нажатия блокируются.
- **Трефа → Secret Ending.** Любой другой ключ → Rabbit Video 1 → WAKE UP → Rabbit Video 2 → WAKE UP → Wake Up Ending.
- Кнопка **WAKE UP** расположена **по центру видеоплеера** и появляется **сразу при запуске первого видео с Кроликом**, а не под четырьмя ключами. Второе нажатие запускает финальное видео.
- Видео меняются внутри **одного существующего** видеоокна. По окончании финала появляется PLAY AGAIN для повторного тестирования.

## Установка
Скопируйте `index.html`, `styles.css`, `game.js` и четыре `key_base_*.png` в папку шестого раунда. **Не перезаписывайте страницы остальных пяти раундов.** Если в проекте уже имеется свой `game.js`, сначала сохраните его копию и согласуйте интеграцию, так как содержимое этого файла не было предоставлено.

## Где заменить видео
Откройте `game.js` — в начале находится `ROUND6.videoFiles`:

| Поле | Путь по умолчанию |
|---|---|
| `intro` | `../../assets/videos/Round6.mp4` |
| `rabbit1` | `../../assets/videos/rabbit1.mp4` |
| `rabbit2` | `../../assets/videos/rabbit2.mp4` |
| `wakeEnding` | `../../assets/videos/wake-ending.mp4` |
| `secretEnding` | `../../assets/videos/secret-ending.mp4` |

Видео не прикладывались; они не включены в архив. Для локального тестирования вы увидите надпись об отсутствии файла, но кнопки перехода работают. При наличии роликов они воспроизводятся внутри исходной области видео.

## Точка попадания ключа
В `game.js` параметр `keyholeTarget: { x: 0.50, y: 0.56 }` задаёт условную точку в окне видео (проценты ширины и высоты). **Её нужно будет точно совместить с замочной скважиной на вашем финальном кадре.** Рендеринг ключа выполняется HTML/CSS/JS и не меняет оригинальное видео.

## Важно для телефона
После выбора ключа скрипт автоматически прокручивает экран к видеоплееру, чтобы анимация полёта была видна и на узком экране. Если Safari запрещает автоматическое воспроизведение видео со звуком, появляется резервная кнопка `PLAY VIDEO WITH SOUND`.

Ролики должны быть закодированы в поддерживаемом браузерами формате, например H.264/AAC в MP4.
